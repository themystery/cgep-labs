The module enforces several NIST SP 800-53 controls, including SC-12 (Cryptographic Key Establishment and Management), SC-13 (Cryptographic Protection), SC-28 (Protection of Information at Rest), AU-11 (Audit Record Retention), CM-6 (Configuration Settings), and AC-3 (Access Enforcement). Together, these controls strengthen the resource by addressing encryption and key management, data protection, audit-log retention, secure configuration, and appropriate access enforcement.
